The implementation is to be done in python using micropython to run on a raspberry pi pico go
To access any function first a object of the class type needs to be created

this is the path from the root you code will be at the python root

Your main file must be named main.py


Here are all relevant functions that can be used

Waveshare.battery:
class: Battery
functions:
get_percentage()
get_voltag()

Waveshare.motor:
class: Motor
functions:
backward(self, speed: int) -> None
forward(self, speed: int) -> None
left(self, speed: int) -> None
right(self, speed: int) -> None
set(self, left_speed: int, right_speed: int) -> None
stop(self) -> None

Waveshare.ultrasonic_sensor:
class: UltrasonicSensor
functions:
distance(self) -> float

Waveshare.infrared:
class: Infrared
functions:
dsl(self) -> bool
dsr(self) -> bool

Files for these functions already exist at "ROOT/Waveshare", so no need to create placeholders
